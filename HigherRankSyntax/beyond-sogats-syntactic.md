# Second-order theories, syntactically

The syntactic criterion for a higher-rank theory to be a SOGAT, and the
translation witnessing it. Companion to `beyond-sogats-semantics.md`, whose
Definition 2.1 this file sanity-checks.

Marks: `[proved]`, `[routine]`, `[open]`.

---

## 0. Purpose

`beyond-sogats-semantics.md` defines a first-order presentation of `(Ξ, 𝒫)` by
abstracting the shape of Kaposi–Xie's Construction 26. The abstraction is
justified only if it **recovers** that construction on the theories that are
already SOGATs. Establishing that needs two things this file supplies:

```text
(a)  a translation  ⌈−⌉ : (Ξ,𝒫) ↦ Ω,  Ω a ToS⁺ signature
(b)  Mod_𝒞(Ξ,𝒫) ≅ Mod_𝒞(⌈Ξ⌉),  naturally in 𝒞
     where Mod_𝒞(⌈Ξ⌉) := Tm_{PSh(𝒞)} ⋄ ⟦⌈Ξ⌉⟧ is the NAIVE semantics of the
     translated signature — Definition 1.1 of beyond-sogats-semantics.md
```

and, before either, a criterion saying which `(Ξ,𝒫)` are in scope.

---

## 1. The criterion

Recall `rank 𝟙 = 0` and `rank Θ = max_z (rank (Θ.binding z) + 1)`, so
`rank Ξ ≤ 3` iff every binding telescope of `Ξ` has rank `≤ 2`.

**Definition 1.1.** `(Ξ, 𝒫)` is **second-order** if

- **(i)** every entry occurring inside a binding telescope of `Ξ`, at any depth,
  has boundary of the form `of S`;
- **(ii)** `rank Ξ ≤ 3`;
- **(iii)** `𝒫` is exactly the subpresheaf generated by the extensions
  `[x : of S]` for the `sort`-boundaried slots `S` of `Ξ`.

Top-level `sort` and `eq` slots of `Ξ` are unrestricted: those are the sort
declarations and the equations.

**Remark 1.2.** The clauses are not stipulations; each is the definedness
condition of one clause of Construction 2.1. See Proposition 2.2.

**Remark 1.3.** (i) and (ii) are independent. `Bind([X : sort, x : of X], b)` has
rank 2, hence satisfies (ii), and violates (i).

## 2. The translation

**Construction 2.1.** For `(Ξ,𝒫)` second-order, define `⌈Ξ⌉ : Ty ⋄` in `ToS⁺`.

Telescopes, as an iterated dependent sum:

```text
⌈𝟙⌉              := ⊤
⌈[z] ⋈ Θ⌉        := Σ ⌈z⌉ (λ_. ⌈Θ⌉)
```

Entries of a binding telescope, as sort codes `⟨−⟩ : Tm U`:

```text
⟨x : of S⟩             := el⁺ S                             S : Tm U⁺ by (i), (iii)
⟨g : Bind(Ψ, of S)⟩    := π⁺ S₁ (π⁺ S₂ (… (π⁺ S_k (el⁺ S))))
                          for Ψ = [y₁ : of S₁, …, y_k : of S_k]
```

Binding telescopes, as iterated products:

```text
⌈𝟙⌉ X            := X
⌈[w] ⋈ Θ⌉ X      := Π ⟨w⟩ (λ_. ⌈Θ⌉ X)
```

Slots:

```text
Bind(𝟙, sort)          := U⁺
Bind(Θ, sort)          := ⌈Θ⌉ U⁺
Bind(Θ, of S)          := ⌈Θ⌉ (El S)
BindEq(Θ, b, l, r)     := ⌈Θ⌉ (Eq l r)
```

**Proposition 2.2.** `⌈−⌉` is defined precisely on the second-order theories.
`[routine]`

*Proof.* Each clause is legal `ToS⁺`: `U⁺ : Ty`, so `Π`'s codomain may be `U⁺`;
`Eq` is available at any `Ty`; `Π`'s domain must be a code `Tm U`, which
`⟨−⟩` supplies. Conversely, dropping a hypothesis breaks exactly one clause.

```text
(ii) fails    an entry binds a binder  ⟹  ⟨−⟩ needs π⁺ with a π⁺-domain,
                                          but π⁺'s domain is Tm U⁺, and U⁺
                                          has no formers
(i) fails     a sort entry             ⟹  Π would need domain U, not a code
              an eq entry              ⟹  Π would need domain Eq l r : Ty
```

`(iii)` is not used here; it is consumed in §3. ∎

**Remark 2.3.** `⌈−⌉` is **not** inverse to the translation `ToS⁺ ↦` telescopes,
which curries `π⁺` into bindings and normalizes `Eq` pointwise, both only up to
isomorphism. The round trip is not the identity on signatures. The two are
mutually inverse **on models**, which is what §3 asserts and all that is needed.

## 3. Adequacy

**Proposition 3.1.** For `(Ξ,𝒫)` second-order and `𝒞` small, there is a bijection
`Mod_𝒞(Ξ,𝒫) ≅ Mod_𝒞(⌈Ξ⌉)`, natural in `𝒞`. `[open]`

*Proof sketch.* By `semantics.md` Lemma 3.3 the left side is a tuple with one
component per slot of `Ξ`, the component at `z` a section of
`Π_{⟦Θ_z⟧} ⟦b_z⟧`; the right side is a tuple over the iterated `Σ` of `⌈Ξ⌉`.
Compare componentwise. Three points carry content.

**(1) `sort` against `U⁺`.** `⟦sort⟧ = 𝒰`, *all* small types, with
representability imposed externally by `𝒫`; `⟦U⁺⟧ I γ = Ty⁺(よI)`, the locally
representable types, imposed internally. The required bijection

```text
{ S ∈ 𝒰(I) | S locally representable }   ≅   Ty⁺(よI)
```

is definitional, provided every `sort`-slot's interpretation is forced
representable. That is clause (iii): `𝒫` contains `[x : of S]` for each declared
`S`, and local representability of that display is local representability of
`El ⟦S⟧`.

**(2) Binder entries against `π⁺`-codes.** `π⁺ a⁺ b` is a *code* in `U` whose
`El` is the product; our entry is interpreted as the product itself. The
bijection is code against decoding, so it uses `El : 𝒰(I) ≅ {small types over よI}`,
which is the definition of the Hofmann–Streicher universe, together with
smallness of `Π_A B`, which holds as `𝒞` is small.

**(3) Naturality.** Under (i)–(iii) every binder domain is `𝒫`-representable, so
every `Π` on both sides is computed by reindexing along a context extension, and
restriction commutes with it. This is the positive half of
`beyond-sogats-semantics.md` Lemma 3.2. ∎

**Remark 3.2.** (1) is the only place a hypothesis is consumed, and it is where
the proposition would fail. If `𝒫` is allowed to be *larger* than (iii) permits,
the `sort` component no longer matches `Ty⁺` and `(Ξ,𝒫)` has no `ToS⁺` signature
even at rank 3. This is why (iii) reads "exactly" and not "contains".

**Remark 3.3.** `J_𝒞(Ξ)` is an iterated `Σ` — a list, in `initiality.md`'s
presentation — and `⟦⌈Ξ⌉⟧` is an iterated `Σ` in `PSh(𝒞)`; matching them uses the
unitor and associator. Harmless, since 3.1 asserts only a bijection and the
isomorphisms are natural, so clause (4) of `beyond-sogats-semantics.md`
Definition 2.1 survives.

**Corollary 3.4.** Every second-order `(Ξ,𝒫)` has a first-order presentation, with
`B := Cat⋄` and `S := ⟦⌈Ξ⌉⟧_E(−) ⋄_D(−) tt`. `[open]`

*Proof.* Take `B := Cat⋄` and `S(𝒞) := ⟦⌈Ξ⌉⟧_E(𝒞) ⋄_D(𝒞) tt`, which is
Construction 26 applied to `⌈Ξ⌉`. Then

```text
S(𝒞)  ≅  Tm_{PSh(𝒞)} ⋄ ⟦⌈Ξ⌉⟧  =  Mod_𝒞(⌈Ξ⌉)  ≅  Mod_𝒞(Ξ, 𝒫)
         └──── Theorem 22 ────┘                 └─ Proposition 3.1 ─┘
```

giving clause (3); clause (4) holds by Proposition 3.1's naturality. ∎

## 4. The two notions differ

**Proposition 4.1.** `{ second-order }` is a proper subclass of
`{ has a first-order presentation }`. `[routine]`

*Proof.* Take `Ξ = [A : sort, Z : ((A→A)→A) → A]` of
`beyond-sogats-semantics.md` 3.1, with `𝒫` containing every binding telescope.
Then `rank Ξ = 4`, so (ii) fails and `Ξ` is not second-order; and `𝒫` is larger
than (iii) permits, so (iii) fails too. Yet Proposition 4.3 of that file gives it
a first-order presentation, by reification. ∎

**Remark 4.2.** So the syntactic criterion is not load-bearing for the main
results: Propositions 3.3 and 4.3 of `beyond-sogats-semantics.md` are about
first-order presentations, and Definition 1.1 is needed only for Corollary 3.4 —
the sanity check that Definition 2.1 abstracts Construction 26 correctly.
Reification is exactly what separates the two classes.
