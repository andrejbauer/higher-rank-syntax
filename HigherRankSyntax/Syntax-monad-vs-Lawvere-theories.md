# Algebras for the syntax monad

## 1. Unfolding the definition

Fix a carrier `C`.  The syntax relative monad is over

```text
J : Arity_C → Set^{Arity_C × Ty_C},
```

Here:

```text
Arity_C
```

is the category whose objects are arities and whose morphisms are renamings.
We also write `Arity_C` for the underlying collection of arity objects when it
appears as an index.  The codomain

```text
Set^{Arity_C × Ty_C}
```

is the category of families of sets indexed by pairs `(α, τ)`, with
`α : Arity_C` and `τ : Ty_C`, and with pointwise maps.

The functor `J` is defined by

```text
J Γ (α, τ) = Γ ∋[τ] α
```

The object part of the relative monad is

```text
T : Arity_C → Set^{Arity_C × Ty_C}
```

with

```text
T Γ (α, τ) = Expr (Γ ⋈ α) τ.
```

So `J Γ` is the family of typed slots of `Γ`, and `T Γ` is the family of
expressions over `Γ`, with residual arity `α` and result type `τ`.

An algebra for this relative monad consists of:

```text
X : Arity_C → Ty_C → Set
```

together with evaluation operations as follows.  For every context `Γ` and
every valuation

```text
v : J Γ → X,
```

that is, every family of maps

```text
v_{α,τ} : (Γ ∋[τ] α) → X(α, τ),
```

we have, for every `(α, τ)`, a function

```text
eval_v^{α,τ} : Expr (Γ ⋈ α) τ → X(α, τ).
```

These evaluations satisfy two laws.

First, variables are interpreted by the valuation:

```text
eval_v(η x) = v(x).
```

Second, evaluation commutes with substitution.  If

```text
σ : J Γ → T Δ
```

is a substitution, then

```text
eval_v(σ† e) = eval_w(e),
```

where `σ†` is Kleisli extension and the new valuation `w : J Γ → X` is
defined by

```text
w(x) = eval_v(σ x).
```

So an algebra is exactly a semantics for expressions under valuations of
slots, compatible with variables and substitution.

The important point is that the carrier of the algebra is not a single set,
but a family:

```text
X(α, τ).
```

The ordinary fibre `X(1, τ)` interprets expressions whose residual arity is
the monoidal unit.  The higher fibres `X(α, τ)` interpret expressions with
residual arity `α`.

## 2. Lawvere algebras as a special case

Voevodsky's comparison says that ordinary single-sorted Lawvere theories are
equivalently relative monads on

```text
Jf : Fin → Set,
Jf(n) = Fin n.
```

For a signature `Σ`, write `Σ_k` for the set of operation symbols of arity
`k`.  The free Lawvere theory generated by `Σ` corresponds to the relative
monad

```text
R_Σ : Fin → Set
```

where `R_Σ(n)` is the set of raw `Σ`-terms in variables `Fin n`.  Its unit is
variable inclusion, and its Kleisli extension is ordinary simultaneous
substitution.

We obtain this relative monad from our syntax as follows.

Choose a carrier `C_Σ` with one result type:

```text
Ty_C_Σ = {*}.
```

Let the arity monoid be freely generated by two elements:

```text
s, v_1.
```

Here `s` is the operation-symbol prefix, and `v_1` is the one-variable arity.
Write the monoid product as `⋈` and the unit as `1`.  For `n ≥ 1`, define

```text
v_n := v_1^n.
```

Define slots on the free generators by

```text
v_1 ∋[*] 1      = {*}
v_1 ∋[*] α      = ∅       for α ≠ 1,

s ∋[*] 1        = Σ_0
s ∋[*] v_k      = Σ_k     for k ≥ 1
s ∋[*] α        = ∅       for α not equal to 1 or to some v_k.
```

Slots of products are then determined by the carrier product law:

```text
(Γ ⋈ Δ) ∋[*] α ≅ (Γ ∋[*] α) ⊔ (Δ ∋[*] α).
```

In particular,

```text
v_n ∋[*] 1 ≅ Fin n        (n ≥ 1),
v_n ∋[*] α = ∅            for α ≠ 1.
```

Thus `v_n` is the arity of `n` variables for `n ≥ 1`, the unit `1` is the
arity of no variables, and `s` is the fixed arity whose slots are the
operation symbols.
Let

```text
i : Fin → Arity_C_Σ
```

be defined by

```text
i(0) = 1,
i(n) = v_n        (n ≥ 1).
```

On morphisms, `i` sends a function `Fin n → Fin m` to the corresponding
renaming `i(n) → i(m)`.  This identifies `Fin` with the full subcategory of
`Arity_C_Σ` spanned by `1` and the positive variable arities `v_n`.

Let

```text
ev_1 : Set^{Arity_C_Σ × {*}} → Set
```

be evaluation at `(1,*)`.  For the slot functor

```text
J Γ (α,*) = Γ ∋[*] α
```

we get

```text
(ev_1 ∘ J ∘ i)(n)
  = J(v_n)(1,*)
  = v_n ∋[*] 1
  = Fin n.
```

Hence `ev_1 ∘ J ∘ i = Jf`.

The ordinary Lawvere relative monad is not obtained from the ambient syntax
functor

```text
T Γ (α,*) = Expr (Γ ⋈ α) *
```

because `(ev_1 ∘ T ∘ i)(n) ≅ Expr v_n *`, which sees only variables.  The
operation-symbol arity `s` has to be kept as a fixed prefix.  Define instead

```text
T'_s Γ (α,*) := Expr (s ⋈ Γ ⋈ α) *.
```

This is a relative monad over the same `J`.  The unit sends a slot
`x : Γ ∋[*] α` to its eta-expansion after including it as a slot of
`s ⋈ Γ`.  Given

```text
f : J Γ → T'_s Δ,
```

the Kleisli extension

```text
f† : T'_s Γ → T'_s Δ
```

recursively substitutes `f` for the slots coming from `Γ`, leaves the fixed
prefix `s` as the same prefix in the target, and leaves the residual arity
`α` as residual variables.  The relative-monad laws are exactly the usual
substitution laws with this inert prefix.

Now precompose with `i` and postcompose with `ev_1`.  The resulting relative
monad over `Jf` is

```text
R(n) := (ev_1 ∘ T'_s ∘ i)(n)
      = Expr (s ⋈ v_n ⋈ 1) *
      ≅ Expr (s ⋈ v_n) *.
```

This is naturally isomorphic to the raw `Σ`-term monad `R_Σ`.

The isomorphism is by structural recursion.  A variable `j : Fin n` is sent
to the eta-expansion of the corresponding slot of `v_n`.  An operation
application

```text
c(t_1,...,t_k)      with c ∈ Σ_k
```

is sent to the expression headed by the slot `c : s ∋[*] v_k`; its recursive
arguments are the translations of `t_1,...,t_k`, indexed by the slots

```text
v_k ∋[*] 1 = Fin k.
```

Conversely, every expression in `Expr (s ⋈ v_n) *` has head either a variable
slot from `v_n` or an operation-symbol slot from `s`.  The first case gives a
variable.  The second case gives some `c ∈ Σ_k` together with one recursive
argument for each element of `Fin k`, hence an ordinary application
`c(t_1,...,t_k)`.  These two translations are inverse by induction on
expressions and terms.

The isomorphism respects the relative-monad structure.  The unit is variable
inclusion on both sides.  A Kleisli map

```text
Fin n → R(m)
```

chooses an `m`-variable term for each of the `n` variables.  Its Kleisli
extension in `T'_s` replaces exactly the `v_n`-slots by those chosen terms.
The operation-symbol slots live in the fixed prefix `s`, so they are preserved
and substitution passes recursively through their arguments.  This is ordinary
simultaneous substitution of first-order terms.

Therefore

```text
ev_1 ∘ T'_s ∘ i
```

over

```text
ev_1 ∘ J ∘ i = Jf
```

is precisely the `Jf`-relative monad corresponding to the free Lawvere theory
generated by `Σ`.

Its algebras are the usual `Σ`-algebras.  Unfolded as relative-monad
algebras, such an algebra is a set `M` with evaluation maps

```text
eval_ρ : R_Σ(n) → M
```

for every valuation `ρ : Fin n → M`, compatible with variables and
substitution.  This is equivalent to giving operations

```text
⟦c⟧ : M^k → M        for each c ∈ Σ_k.
```

Given evaluation maps, define `⟦c⟧(a_1,...,a_k)` by evaluating the term
`c(x_1,...,x_k)` under the valuation `x_i ↦ a_i`.  Conversely, given the
operations `⟦c⟧`, evaluate terms recursively.  The variable and substitution
laws say exactly that these two descriptions agree.

If a Lawvere theory is presented by equations `(Σ,E)`, then one further
quotients the raw term relative monad by the substitution-stable congruence
generated by `E`.  Without this quotient, the construction above gives the
free, equation-free Lawvere theory on `Σ`.
