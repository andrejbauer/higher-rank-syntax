# Well-formed equational telescopes — definitions and propositions

Distilled from `equational-telescopes.md`: the definitions, constructions and
proof obligations only. Everything is stated over a fixed carrier `C`.

> **Theorem.** Over the category of contexts, the well-formed decorated telescopes
> — carrying as their equivalence the equality generated by the equations they
> contain — form a presheaf `𝒯₀` which is a monoid object for dependent context
> extension; and `q : 𝒯̃₀ ⟶ 𝒯₀`, from telescopes-with-a-filling, is a representable
> natural transformation: a natural model whose types are telescopes and whose
> comprehension is context extension.

**Variables.** `Ξ, Ψ, Γ` ambients; `Θ, Δ` telescopes over an ambient;
`Ω, α, Λ, Φ` bare arities; `x, z, q, w` slots; `σ, θ, τ, κ` substitutions;
`e, l, r, S` expressions; `β` a boundary.

**Erasure.** `|Θ|` is the `arity` field of `Θ : dTel Ω`, written out wherever an
arity is expected: `Expr |Ξ|`, `dTel |Ξ|`, `|Θ| ∋ α`, `|Θ| ⇒ |Ξ|`.

---

## 1. The raw layer (existing)

**1.1 Arities.** `C.Arity` is a monoid, written `Γ ⋈ Δ` with unit `1`. `Γ ∋ α` is
the well-ordered type of slots of `Γ` with binding arity `α`. Each slot splits its
arity, `C.before x ⋈ C.after x = Γ` (`C.factor x`), giving
`C.inclusion x : C.before x →ʳ Γ`. The unit has no slots; the slots of `Γ ⋈ Δ` are
those of `Γ` then those of `Δ`, injected by `C.inl`, `C.inr`, with case analysis
`C.copair`. `C.subWf` is the well-founded relation making a slot's binding arity
smaller than the arity it sits in.

**1.2 Renamings.** `Γ →ʳ Δ := ∀ ⦃α⦄, Γ ∋ α → Δ ∋ α`, with `𝟙ʳ`, `∘ʳ`,
`ρ ⇑ʳ Ξ : Γ ⋈ Ξ →ʳ Δ ⋈ Ξ`, and `Renaming.prefixed Ω ρ : Ω ⋈ Γ →ʳ Ω ⋈ Δ`.

**1.3 Expressions.**

```lean
inductive Expr : C.Arity → Type
  | ap {Γ α} (x : Γ ∋ α) (args : ∀ ⦃Λ⦄, α ∋ Λ → Expr (Γ ⋈ Λ)) : Expr Γ
```

Free: no boundary and no judgement occurs in it. `Expr.η : Γ ∋ α → Expr (Γ ⋈ α)`.

**1.4 Substitutions.**

```lean
abbrev Subst (Δ Γ : C.Arity) := ∀ ⦃α⦄, Δ ∋ α → Expr (Γ ⋈ α)
infixr:25 " ⇒ " => Subst
```

One expression over `Γ` for each slot of `Δ`, in the arity extended by that slot's
binding arity. The arity whose slots are consumed comes first, as for renamings.

```
Subst.id Γ        : Γ ⇒ Γ                                    fun x => Expr.η x
Subst.ofRenaming  : (Γ →ʳ Δ) → (Γ ⇒ Δ)                       fun ⦃_⦄ x => Expr.η (ρ x)
Subst.act         : Δ ⇒ (Γ ⋈ Ξ) → (Φ : C.Arity) → Expr (Γ ⋈ Δ ⋈ Φ) → Expr (Γ ⋈ Ξ ⋈ Φ)
Subst.comp        : Δ ⇒ (Γ ⋈ Θ) → Θ ⇒ (Γ ⋈ Ξ) → Δ ⇒ (Γ ⋈ Ξ)
Subst.lift        : Γ ⇒ Δ → (Φ : C.Arity) → (Γ ⋈ Φ) ⇒ (Δ ⋈ Φ)
```

**1.5 Slot paths.** `SlotPath Δ Φ α` addresses a slot reached from `Δ` by entering
binding arities; `α` is its binding arity and `Φ` accumulates what precedes it.

```lean
inductive SlotPath : C.Arity → C.Arity → C.Arity → Type where
  | here   {Δ α}     (x : Δ ∋ α)                      : SlotPath Δ (C.before x) α
  | nested {Δ β Φ α} (x : Δ ∋ β) (p : SlotPath β Φ α) : SlotPath Δ (C.before x ⋈ Φ) α
```

**1.6 The monoid laws on arities are definitional.** `1 ⋈ Γ = Γ`, `Γ ⋈ 1 = Γ` and
`Γ ⋈ Δ ⋈ Φ = Γ ⋈ (Δ ⋈ Φ)` hold by `rfl` and transport `∋`, `Bd`, `dTel` with no
cast. They are suppressed throughout. The carrier's own equations — `C.factor`,
`C.before_inl` — are propositional and do need transports.

**1.7 `Expr` is a relative monad over the slot functor.** `SyntaxMonad C`, with

```
J Γ = (α ↦ Γ ∋ α)        T Γ = (α ↦ Expr (Γ ⋈ α))
```

unit `Expr.η`, extension `Subst.act`, laws `act_η`, `act_id`, `act_comp`. A Kleisli
morphism is a substitution (`syntaxKleisliHomEquiv = Equiv.refl`), so `Kl(T)` has
raw arities as objects and `Hom Γ Ξ = Γ ⇒ Ξ`.

## 2. Boundaries

**Definition 2.1.**

```lean
inductive Bd (Ω : C.Arity) : Type where
  | sort
  | of (S : Expr Ω)
  | eq (l r : Expr Ω)
```

`sort` declares its slot a sort, `of S` an object of `S`, `eq l r` that the
equation `l ≈ r` holds. `eq` is the one change to `Typing/Boundary.lean`. An
equational slot's binding telescope is what its equation is quantified over.

**2.2 Actions.** Componentwise:

```lean
Bd.rename (ρ : Γ →ʳ Δ) : Bd Γ → Bd Δ
  | .sort => .sort  | .of S => .of (⟦ρ⟧ʳ S)   | .eq l r => .eq (⟦ρ⟧ʳ l) (⟦ρ⟧ʳ r)

Bd.act (σ : Δ ⇒ (Γ ⋈ Ξ)) (Φ) : Bd (Γ ⋈ Δ ⋈ Φ) → Bd (Γ ⋈ Ξ ⋈ Φ)
  | .sort => .sort  | .of S => .of (σ.act Φ S)  | .eq l r => .eq (σ.act Φ l) (σ.act Φ r)

Bd.instantiate (σ : Δ ⇒ Γ) : Bd (Γ ⋈ Δ) → Bd Γ    :=  Bd.act (Ξ := 1) σ 1
```

**Lemma 2.3.** Both actions preserve the constructor; whether a boundary is an
`eq` is therefore invariant, and is written `Bd.isEq`.

## 3. Telescopes

### 3.1 Decorations

```lean
abbrev Decoration (Ω Δ : C.Arity) : Type :=
  ∀ ⦃Φ α⦄, SlotPath Δ Φ α → Bd (Ω ⋈ Φ ⋈ α)

structure dTel (Ω : C.Arity) where
  arity      : C.Arity
  decoration : Decoration Ω arity
```

### 3.2 Existing operations

```lean
Decoration.rename     (ρ : Γ →ʳ Δ)      : Decoration Γ Ξ → Decoration Δ Ξ
Decoration.substitute (σ : Γ ⇒ (S ⋈ Δ)) : Decoration (S ⋈ Γ ⋈ Φ) Ξ → Decoration (S ⋈ Δ ⋈ Φ) Ξ
Decoration.act        (σ : Γ ⇒ Δ)       : Decoration Γ Ξ → Decoration Δ Ξ
Decoration.empty                        : Decoration Ω 1
Decoration.concatenate                  : Decoration Ω Γ → Decoration (Ω ⋈ Γ) Δ → Decoration Ω (Γ ⋈ Δ)
```

with the same for `dTel`, satisfying `concatenate_empty_left`,
`concatenate_empty_right`, `concatenate_assoc`, `act_empty`, `act_concatenate`,
`act_id`, `act_comp`.

**Proposition 3.2.1.** All three actions leave the underlying arity alone,
definitionally: each is `arity := Θ.arity`. Every comparison of arities across an
action below appeals to this.

### 3.3 Ambients and extension

**Definition.** An **ambient** is a `Ξ : dTel 1`; `Ambient := dTel 1`; the empty
ambient is `𝟙`.

```lean
dTel.concatenate {Ω} (Θ : dTel Ω) (Δ : dTel (Ω ⋈ |Θ|)) : dTel Ω
  arity      := |Θ| ⋈ |Δ|
  decoration := Decoration.concatenate Θ.decoration Δ.decoration
```

`Ξ ⋈ Θ` is this at `Ω := 1`: for `Ξ : Ambient` and `Θ : dTel |Ξ|` it is an ambient
with `|Ξ ⋈ Θ| = |Ξ| ⋈ |Θ|`. Extension associates to the left, so `Ξ ⋈ Θ ⋈ Δ`
requires `Δ : dTel |Ξ ⋈ Θ|`.

### 3.4 The three projections of a slot

For `Ω : C.Arity`, `Θ : dTel Ω`, `z : |Θ| ∋ Λ`:

```
Θ.before   z  :  dTel Ω                                    entries of Θ preceding z
Θ.binding  z  :  dTel (Ω ⋈ |Θ.before z|)                   entries z binds
Θ.boundary z  :  Bd   (Ω ⋈ |Θ.before z| ⋈ |Θ.binding z|)   what z is declared to be
```

with `|Θ.before z| = C.before z` and `|Θ.binding z| = Λ`. For an ambient take
`Ω := |Ξ|`; for an ambient's own slots take `Ω := 1`.

```lean
Θ.binding  z := ⟨Λ, Θ.decoration.nested z⟩            -- exists
Θ.boundary z := Θ.decoration.boundary z               -- exists

SlotPath.inl : SlotPath Γ Φ α → SlotPath (Γ ⋈ Δ) Φ α  -- new
  | .here x     => C.before_inl x ▸ .here (C.inl x)
  | .nested x p => C.before_inl x ▸ .nested (C.inl x) p

Decoration.restrict (D : Decoration Ω (Γ ⋈ Δ)) : Decoration Ω Γ := D ∘ SlotPath.inl
Θ.before z := restriction of Θ along C.factor z       -- new
```

### 3.5 Weakening `⇑`

For `Ω`, `Θ : dTel Ω`, `z : |Θ| ∋ Λ`, weakening is the action of

```
Renaming.prefixed Ω (C.inclusion z)  :  Ω ⋈ |Θ.before z| →ʳ Ω ⋈ |Θ|
```

on the three families, and, through a suffix `Φ : C.Arity` by `⇑ʳ`, on three more:

```
⇑ : Expr (Ω ⋈ |Θ.before z|)      → Expr (Ω ⋈ |Θ|)          Renaming.act
⇑ : Bd   (Ω ⋈ |Θ.before z|)      → Bd   (Ω ⋈ |Θ|)          Bd.rename
⇑ : dTel (Ω ⋈ |Θ.before z|)      → dTel (Ω ⋈ |Θ|)          Decoration.rename

⇑ : Expr (Ω ⋈ |Θ.before z| ⋈ Φ)  → Expr (Ω ⋈ |Θ| ⋈ Φ)
⇑ : Bd   (Ω ⋈ |Θ.before z| ⋈ Φ)  → Bd   (Ω ⋈ |Θ| ⋈ Φ)
⇑ : dTel (Ω ⋈ |Θ.before z| ⋈ Φ)  → dTel (Ω ⋈ |Θ| ⋈ Φ)
```

the first three being the case `Φ = 1`. **Base weakening** is the same along the
unique `1 →ʳ Ω`, used at `⇑ : dTel 1 → dTel Ω` and, with `Ψ : dTel 1` as suffix,
at `⇑ : Expr |Ψ| → Expr (Ω ⋈ |Ψ|)` and `⇑ : Bd |Ψ| → Bd (Ω ⋈ |Ψ|)`.

### 3.6 Instantiation `⋆`

For `Ω, α : C.Arity` and `σ : α ⇒ Ω`, and a suffix `Φ : C.Arity`:

```
σ ⋆ − : Expr (Ω ⋈ α) → Expr Ω          σ ⋆ − : Expr (Ω ⋈ α ⋈ Φ) → Expr (Ω ⋈ Φ)
σ ⋆ − : Bd   (Ω ⋈ α) → Bd   Ω          σ ⋆ − : Bd   (Ω ⋈ α ⋈ Φ) → Bd   (Ω ⋈ Φ)
σ ⋆ − : dTel (Ω ⋈ α) → dTel Ω          σ ⋆ − : dTel (Ω ⋈ α ⋈ Φ) → dTel (Ω ⋈ Φ)
```

`Subst.act`, `Bd.act`, `Decoration.substitute`, at replacement `1`; the left column
is the case `Φ = 1`, and its `Bd` line is `Bd.instantiate`. Neither the consumed
block nor the suffix is decorated: `⋆` is arity-level.

**Restriction.** For `Θ : dTel Ω`, `σ : |Θ| ⇒ Ω` and `z : |Θ| ∋ Λ`:

```
σ ↾ z  :=  σ ∘ C.inclusion z            :  |Θ.before z| ⇒ Ω
(σ ↾ z) ⋆ Θ.binding  z                  :  dTel Ω
(σ ↾ z) ⋆ Θ.boundary z                  :  Bd (Ω ⋈ |Θ.binding z|)
```

both at block `α := |Θ.before z|`, the binding at `Φ = 1` and the boundary at
`Φ := |Θ.binding z|`.

**Between two ambients.** For `σ : |Ψ| ⇒ |Ξ|` and `e : Expr |Ψ|`, the substitution
is 3.6 at `Ω := |Ξ|`, `α := |Ψ|`, and the argument is corrected by base weakening:

```
σ ⋆ e  :=  σ ⋆ ⇑e   :  Expr |Ξ|
```

and likewise on `Bd |Ψ|` and `dTel |Ψ|`.

### 3.7 Raw telescopes are a monoid (existing)

`DTel : Kl(T) ⥤ Type` is arity-shaped, an object of

```
ArityMod T := Over (arityConst T)        (M ⊗ N) Ω := Σ (m : M Ω), N (Ω ⋈ |m|)
```

**Theorem.** `DTel` is a monoid object in `(ArityMod T, ⊗, I)`, with unit
`dTel.empty`, multiplication `concatenate`, laws the three `concatenate` lemmas.
The multiplication is dependent, and the base is extended by a **raw arity**.

## 4. The boundary of an expression

**4.1.** For an ambient `Ξ` and `ap x args : Expr |Ξ|`:

```
x    : |Ξ| ∋ α
args : ∀ ⦃Λ⦄, α ∋ Λ → Expr (|Ξ| ⋈ Λ)   =   α ⇒ |Ξ|   =   |⇑(Ξ.binding x)| ⇒ |Ξ|
```

the last equality by 3.2.1: the arguments of an application are a substitution
filling the telescope its head binds.

**Definition 4.2.**

```
Ξ.boundaryOf : Expr |Ξ| → Bd |Ξ|
Ξ.boundaryOf (ap x args) := args ⋆ ⇑(Ξ.boundary x)
```

3.4 and 3.5 at `Ω := 1`, `Θ := Ξ`: `Ξ.boundary x : Bd (|Ξ.before x| ⋈ α)` is
weakened at suffix `Φ := α` to `Bd (|Ξ| ⋈ α)`, then instantiated by `args` at
`Φ = 1`. In code: `Bd.instantiate args (Bd.rename (Renaming.prefixed 1 (C.inclusion x) ⇑ʳ α) (Ξ.boundary x))`.

Not a recursion — only the head is inspected — and total, a decoration giving a
boundary to every slot.

## 5. Equality of boundaries

**Definition 5.1.** For an ambient `Ξ` and a relation `≈` on `Expr |Ξ|`, extend it
to `Bd |Ξ|` by

```
sort ≈ sort        of S ≈ of S' iff S ≈ S'        eq l r ≈ eq l' r' iff l ≈ l' and r ≈ r'
```

and no other pairs; an equivalence whenever `≈` is. `Ξ ⊢ − ≈ −` is written for
expressions (6.5), boundaries (here) and telescopes (7.4); the arguments fix which.

## 6. The judgements

**6.1.** Three relations, indexed by an arbitrary ambient — well formed or not —
defined by one simultaneous induction:

```
Wf_e : (Ξ : Ambient) → Expr |Ξ| → Prop                         written  Ξ ⊢ e
Eq   : (Ξ : Ambient) → Expr |Ξ| → Expr |Ξ| → Prop              written  Ξ ⊢ e ≈ e'
Wf_s : (Ξ : Ambient) → (Θ : dTel |Ξ|) → (|Θ| ⇒ |Ξ|) → Prop     written  Ξ ⊢ σ : Θ
```

`Wf_s` is not itself inductive: 6.3 is a universally quantified conjunction of
`Wf_e` and `Eq` premises.

**Notation 6.2.** For `e : Expr |Ξ|` and `β : Bd |Ξ|`,

```
Ξ ⊢ e : β     for     Ξ ⊢ e   and   Ξ ⊢ Ξ.boundaryOf e ≈ β
```

An abbreviation, not a primitive judgement. `β` occurs once, as the right argument
of an `≈`, so `β ↦ (Ξ ⊢ e : β)` is `≈`-invariant by construction and conversion
needs no rule.

**Definition 6.3 (filling).** For an ambient `Ξ`, `Θ : dTel |Ξ|` and
`σ : |Θ| ⇒ |Ξ|`, say `Ξ ⊢ σ : Θ` when for every `z : |Θ| ∋ Λ`, writing
`κ := σ ↾ z`:

```
κ ⋆ Θ.boundary z = .eq l r  :   Ξ ⋈ κ ⋆ Θ.binding z ⊢ l ≈ r
otherwise                   :   Ξ ⋈ κ ⋆ Θ.binding z ⊢ σ z : κ ⋆ Θ.boundary z
```

The branch is legitimate by Lemma 2.3. At an equational slot the premise
constrains `σ`'s earlier components only: `σ z` does not occur in it.

**Definition 6.4 (well-formedness).** One clause, for `x : |Ξ| ∋ α` and
`args : α ⇒ |Ξ|`:

```
   ¬ (Ξ.boundary x).isEq        Ξ ⊢ args : ⇑(Ξ.binding x)
  ─────────────────────────────────────────────────────────
                     Ξ ⊢ ap x args
```

The first premise keeps an equational slot from being referred to; `Expr` is free
over the raw arity, so `ap w args` exists for equational `w` like any other.

**Definition 6.5 (equality).** `Ξ ⊢ e ≈ e'` is generated by three clauses.

1. **equivalence** — at each ambient, symmetry and transitivity unrestricted, and

   ```
      Ξ ⊢ e
   ────────────
    Ξ ⊢ e ≈ e
   ```

2. **hypothesis** — for `q : |Ξ| ∋ Λ` with `Ξ.boundary q = .eq l r`,

   ```
    Ξ ⋈ ⇑(Ξ.binding q) ⊢ ⇑l          Ξ ⋈ ⇑(Ξ.binding q) ⊢ ⇑r
   ───────────────────────────────────────────────────────────
             Ξ ⋈ ⇑(Ξ.binding q)  ⊢  ⇑l ≈ ⇑r
   ```

   an equational slot asserting its equation, the entries it binds left free.

3. **substitution** — for ambients `Ψ, Ξ`, expressions `e, e' : Expr |Ψ|` and
   substitutions `σ, θ : |Ψ| ⇒ |Ξ|` with `Ξ ⊢ σ : ⇑Ψ` and `Ξ ⊢ θ : ⇑Ψ`, agreeing
   at every **non-equational** `z : |Ψ| ∋ Λ` in the sense
   `Ξ ⋈ (σ ↾ z) ⋆ (⇑Ψ).binding z ⊢ σ z ≈ θ z`:

   ```
      Ψ ⊢ e ≈ e'
   ──────────────────────
      Ξ ⊢ σ ⋆ e ≈ θ ⋆ e'
   ```

Three points of the definition, each load-bearing. The well-formedness premises on
clauses 1 and 2 are what keep `≈` on the well-formed expressions; without either,
an unconstrained filler at an equational slot collapses the relation through clause
3. Equational `z` are excluded in clause 3 because 6.3 constrains no filler there.
The ambient of clause 3's slotwise premises is built from `σ`; the variant built
from `θ` generates the same relation, by re-instantiating the clause at `(θ, σ)`
and using symmetry.

**Proposition 6.6 (characterization).** `≈` is the least family of equivalence
relations on well-formed expressions that contains the ambient's declared
equations and for which well-formed substitution is a congruence — that is, for
which `⋆` descends to `≈`-classes in both arguments, the expression and the
substitution.

**Theorem 6.7 (congruence).** For `x : |Ξ| ∋ α` and `args, args' : α ⇒ |Ξ|` with
`ap x args` and `ap x args'` well formed, writing `Δ := ⇑(Ξ.binding x)`:

```
for every non-equational z : |Δ| ∋ Λ :   Ξ ⋈ (args ↾ z) ⋆ Δ.binding z ⊢ args z ≈ args' z
──────────────────────────────────────────────────────────────────────────────────────
                         Ξ ⊢ ap x args ≈ ap x args'
```

Proof: `ap x args = args ⋆ Expr.η x` with `Expr.η x : Expr |Ξ ⋈ Δ|`, whose head is
in the prefix block; clause 3 then applies to `Expr.η x ≈ Expr.η x` along
`⟨η, args⟩` and `⟨η, args'⟩`, the substitutions `|Ξ ⋈ Δ| ⇒ |Ξ|` that are the
identity on `Ξ` and the argument family on `Δ`. Sorts are heads, so this covers
congruence of sorts; no theory declares a congruence rule.

**Definition 6.8.** A raw `σ : |Ψ| ⇒ |Ξ|` is **well formed** when `Ξ ⊢ σ : ⇑Ψ` —
6.3 at `Θ = ⇑Ψ`.

**6.9 Encoding.** `Wf_s` is a `∀` of `Wf_e` and `Eq` premises, so either inline it
at its two use sites (6.4, 6.5(3)) and define it afterwards, or make it a third
member of the mutual block with one constructor. Under the first choice
`Ξ ⊢ ap x args` unfolds to a conjunction. 6.3's case distinction is a pattern match
on the boundary, given as two constructors guarded by `Bd.isEq` and its negation,
avoiding a `Prop`-valued `match` inside a constructor type. Nothing later depends
on the choice.

**6.10 Legitimacy.** All three are inductive — the least family closed under the
clauses — so only strict positivity is required, and every occurrence of `Wf_e`
and `Eq` is a premise, none under a negation. No decrease is available: clause 3
concludes about `σ ⋆ e` from a premise about `e`. `Expr` is defined first and
freely, so nothing is inductive–recursive.

## 7. Well-formed telescopes

Recursions on nesting, well-founded by `C.subWf`; they use §6 but are not mutual
with it. The turnstile is §6's, overloaded on its right-hand argument.

**Definition 7.1.** For an ambient `Ξ` and `Θ : dTel |Ξ|`, say `Ξ ⊢ Θ`, named
`Wf_t`, when for every `z : |Θ| ∋ Λ`, writing
`Ξ_z := Ξ ⋈ Θ.before z ⋈ Θ.binding z`:

- `Ξ ⋈ Θ.before z ⊢ Θ.binding z`, and
- one of

  ```
  Θ.boundary z = .sort
  Θ.boundary z = .of S      with   Ξ_z ⊢ S : .sort
  Θ.boundary z = .eq l r    with   Ξ_z ⊢ l,  Ξ_z ⊢ r,  Ξ_z ⊢ Ξ_z.boundaryOf l ≈ Ξ_z.boundaryOf r
  ```

An ambient `Ξ` is **well formed** when `𝟙 ⊢ Ξ`. The conditions at an `eq` entry
make the equation a statement; they do not require `l ≈ r`, the entry being what
declares it.

**Lemma 7.2 (restriction).** `Ξ ⊢ Θ` implies `Ξ ⊢ Θ.before z` at every `z`: by
`C.before_inl` the entries preceding a `w` inside `Θ.before z` are those preceding
it in `Θ`, and `Decoration.restrict` keeps its declaration, so the conditions
imposed at `w` coincide. With 7.1's first bullet and 10.4 this is what makes `Ξ_z`
a well-formed ambient, which §8 presupposes of every ambient it names.

**7.3 Non-circularity.** §6 is defined at every ambient, well formed or not, and
7.1's premises at `z` are stated over `Ξ_z`, built from the entries strictly
preceding `z` and the entries `z` binds — never from `z` itself. Equations declared
earlier are available when a later entry is checked.

**Definition 7.4 (equality of telescopes).** For `Θ, Θ' : dTel |Ξ|`, say
`Ξ ⊢ Θ ≈ Θ'` when `|Θ| = |Θ'|` — strictly, `Expr` being indexed by arities — and
for every `z : |Θ| ∋ Λ`, with `Ξ_z` as in 7.1,

- `Ξ ⋈ Θ.before z ⊢ Θ.binding z ≈ Θ'.binding z`, and
- `Ξ_z ⊢ Θ.boundary z ≈ Θ'.boundary z`.

The ambient used is the one built from `Θ`.

## 8. Proof obligations

Theorems about §§6–7, presupposed by §§9–13. Each is universally quantified over
the data it names, and well-formedness of the ambient is a hypothesis of all of
them.

*How `boundaryOf` moves.*

1. `(Ξ ⋈ Θ).boundaryOf (⇑e) = ⇑(Ξ.boundaryOf e)`, strictly.
2. `Ξ.boundaryOf (σ ⋆ e) ≈ σ ⋆ (Ψ.boundaryOf e)`, for well-formed `σ : |Ψ| ⇒ |Ξ|`.
   Only up to `≈`: the head of `e` is replaced by `σ` at that head, whose declared
   boundary is itself only `≈` the transport of the original's.

*Stability of the judgements.*

3. `Wf_e` is preserved by well-formed substitution.
4. `Wf_s` is preserved by well-formed substitution: from `Γ ⊢ τ : Θ` and
   `σ : Ξ ⟶ Γ`, `Ξ ⊢ (σ ⋆ τ) : σ ⋆ Θ`. At `Θ = ⇑Γ'` this says well-formed
   substitutions are closed under `≫`; `Subst.id` is well formed by (5).
5. For non-equational `x`, `Ξ ⊢ Expr.η x`, and `Ξ.boundaryOf (Expr.η x)` is `x`'s
   declared boundary.
6. Congruence: the rule of 6.7.
7. Presuppositions: if `Ξ ⊢ e ≈ e'` then `Ξ ⊢ e` and `Ξ ⊢ e'`, and
   `Ξ ⊢ Ξ.boundaryOf e ≈ Ξ.boundaryOf e'`.

*The telescope level.*

8. `Wf_t` is preserved by `⇑`: from `𝟙 ⊢ Γ`, `Ξ ⊢ ⇑Γ`.
9. `Wf_t` and `≈` on telescopes are preserved by well-formed substitution. And in
   the other argument: for one `Θ` with `Ξ ⊢ Θ`, two well-formed `σ, θ` agreeing up
   to `≈` at every non-equational slot give `σ ⋆ Θ ≈ θ ⋆ Θ` — clause 6.5(3) applied
   to the decorations, lifted through their suffixes by `Subst.lift`.
10. `Wf_e`, `Eq` and `Wf_t` are invariant under replacing the ambient by an
    `≈`-equal one (7.4).
11. `≈` on telescopes (7.4), `∼` on fillings (9.2), and 13.1's heterogeneous
    comparison of fillings of two `≈`-equal telescopes are equivalence relations.

**8.1 Order of proof.** (2), then (3) and (4) as one simultaneous induction, then
(7). (3) and (4) are mutual: (3) at a head needs (4) for its `Wf_s` premise, (4) at
a slot needs (3) for the filler; the argument at a head runs over the slots of its
binding arity in precedence order, a slot's instantiated boundary depending on the
fillers preceding it. The `Eq` premises inside 6.3 are transported by clause 6.5(3)
as a rule, not by an induction hypothesis, so (3) does not need (7). (7) must come
after (3): at clause 3 its induction hypothesis yields a *derivation* of `Ψ ⊢ e`,
to which (3) is then applied.

**8.2 Notes.** (6) needs (5) and two lemmas of the raw layer, neither mentioning a
judgement: `ap x args = args ⋆ Expr.η x`, by `act_left` and `act_middle`; and
`⟨η, args⟩ ⋆ e = args ⋆ e`, whose nearest existing relatives are `act_idOfη`
(`Instantiation.lean`) and `act_interchange.aux` (`Interchange.lean`). (11) is not
immediate from (10): symmetry of `∼` compares `τ z` and `τ' z` in two different
ambients, so it needs those to be `≈`-equal, which is (9)'s second half given
agreement at the slots preceding `z`; the proof is an induction over the slots in
precedence order. 13.1's relation varies the telescope as well as the filling, so
there both halves of (9) are used, chained by transitivity of `≈` on telescopes.
(10) and (11) are what make §§9–13 well posed; (4) makes `Ctx` a category; (8)
makes 9.3's `Filling Ξ (⇑Γ)` defined at all. The identity substitution's obligation
at an equational slot `q` is discharged by clause 6.5(2) at `q` itself.

## 9. Contexts and fillings

Everything from here is **setoid-first**: each construction is given on
representatives with a proof that it respects an equivalence, and no quotient is
taken. `Γ ⋈ −` takes a telescope to an *object* of `Ctx`, and 8(10) supplies only
an isomorphism `Γ ⋈ Θ ≅ Γ ⋈ Θ'` for `Γ ⊢ Θ ≈ Θ'`, never an equality.

**Definition 9.1 (fillings).** For an ambient `Ξ` and `Θ : dTel |Ξ|` with `Ξ ⊢ Θ`,

```
Filling Ξ Θ  :=  { τ : |Θ| ⇒ |Ξ|  //  Ξ ⊢ τ : Θ }
```

**Definition 9.2.** On `Filling Ξ Θ`,

```
τ ∼ τ'   iff   Ξ ⋈ (τ ↾ z) ⋆ Θ.binding z ⊢ τ z ≈ τ' z    at every non-equational z : |Θ| ∋ Λ
```

Components at equational slots are not compared: nothing constrains them (6.3) and
nothing depends on them (6.5(3)). An equivalence by 8(11).

**Definition 9.3 (contexts).** `Ctx` has the well-formed ambients as objects and

```
Hom Ξ Γ  :=  Filling Ξ (⇑Γ)                    well defined by 8(8)
```

as hom-setoids, with identity `Subst.id` and composition `≫`, both respecting `∼`
by 8(4). `Ctx` is a category enriched in setoids. `σ : Ξ ⟶ Γ` is what type theory
writes `Ξ ⊢ σ : Γ`, so `𝒯₀` below is contravariant; the raw Kleisli category of
1.7 runs the other way. The empty ambient is terminal.

## 10. Telescopes over a context

**Definition 10.1.** For `Γ : Ctx`,

```
𝒯₀ Γ  :=  { Θ : dTel |Γ|  //  Γ ⊢ Θ }        with the equivalence  Γ ⊢ − ≈ −   (7.4)
```

**Definition 10.2 (action).** For `σ : Ξ ⟶ Γ`, `σ ⋆ − : 𝒯₀ Γ → 𝒯₀ Ξ` is 3.6. It
preserves `Wf_t` and `≈` and respects `∼` in `σ`, by 8(9); functoriality is
`act_id` and `act_comp`. So `𝒯₀ : Ctxᵒᵖ ⥤ Setoid`, and `σ ⋆ Θ` is `Θ[σ]`.

**10.3.** `𝒯₀` is not the constant functor on arities: two slots may have the same
binding arity and different decorations, and a well-formed substitution must send
them to expressions well formed under different hypotheses. This is where the
well-formed layer parts from 3.7, whose shape was a raw arity.

**Definition 10.4 (extension).** For `Γ : Ctx` and `Θ : 𝒯₀ Γ`,

```
Γ ⋈ Θ  :  Ctx            3.3, with  𝟙 ⊢ Γ ⋈ Θ  from  𝟙 ⊢ Γ  and  Γ ⊢ Θ
p Γ Θ  :  Γ ⋈ Θ ⟶ Γ      Subst.ofRenaming C.inl,  well formed by 8(5)
```

and for `σ : Ξ ⟶ Γ` the lifted substitution and its square

```
Subst.lift σ |Θ| : Ξ ⋈ σ ⋆ Θ ⟶ Γ ⋈ Θ
(Subst.lift σ |Θ|) ≫ p Γ Θ  =  p Ξ (σ ⋆ Θ) ≫ σ
```

## 11. The monoid of telescopes

**Definition 11.1.** A **telescope-shaped presheaf** is an `M : Ctxᵒᵖ ⥤ Setoid`
with a natural `shape : M ⟶ 𝒯₀`; they form `TelFam := Over 𝒯₀`, the analogue of
3.7's `ArityMod` with the constant module of raw arities replaced by `𝒯₀`.

**Definition 11.2 (tensor and unit).** For `M, N : TelFam`, `σ : Ξ ⟶ Γ`,
`m : M Γ`, `n : N (Γ ⋈ shape m)`:

```
(M ⊗ N) Γ        :=  Σ (m : M Γ), N (Γ ⋈ shape m)
(M ⊗ N) σ (m, n) :=  (M σ m, N (Subst.lift σ |shape m|) n)
shape (m, n)     :=  shape m ⋈ shape n

I Γ := PUnit,    shape _ := 𝟙
```

Well typed by 10.4's square and naturality of `shape`, which gives
`shape (M σ m) = σ ⋆ shape m`. Dependent sequencing, not a product; the second
factor is indexed by the object `Γ ⋈ shape m`, which is why this section needs
representatives and not `≈`-classes.

**Proposition 11.3.** `(TelFam, ⊗, I)` is monoidal, with unitors and associator
`concatenate_empty_left`, `concatenate_empty_right`, `concatenate_assoc`. Triangle
and pentagon are not automatic; they are proved as in `ArityModuleTensor.lean`,
where the comparisons are transports along equalities of arities and the diagrams
follow by proof irrelevance, together with respect for `≈`.

**Theorem 11.4.** `𝒯₀`, with `shape := 𝟙`, is a monoid object in `(TelFam, ⊗, I)`:

```
unit            η : I ⟶ 𝒯₀              Γ ↦ 𝟙
multiplication  μ : 𝒯₀ ⊗ 𝒯₀ ⟶ 𝒯₀       (Θ, Λ) ↦ Θ ⋈ Λ
```

The three laws are the three `concatenate` lemmas; naturality of `μ` is
`act_concatenate`, of `η` is `act_empty`. The operations are literally 3.7's; the
content is that each survives the cut to `Wf_t` and respects `≈`, which is 8(9).

## 12. Expressions and boundaries

**Definition 12.1.** For `Γ : Ctx`,

```
ℰ₀ Γ  :=  { e : Expr |Γ|  //  Γ ⊢ e }      with  Γ ⊢ − ≈ −
ℬ₀ Γ  :=  Bd |Γ|                           with  Γ ⊢ − ≈ −   (§5)
```

**Proposition 12.2.** Both are presheaves `Ctxᵒᵖ ⥤ Setoid`, the action being
`σ ⋆ −`: 8(3) gives `Ξ ⊢ σ ⋆ e`, and clause 6.5(3) — stated for `σ ∼ θ` and
`e ≈ e'` at once — makes the action respect `∼` in the substitution and `≈` in the
expression together. Functoriality is `act_id` and `act_comp`.

**Proposition 12.3.** `boundaryOf` respects `≈` by 8(7) and is natural by 8(2), so
`boundaryOf : ℰ₀ ⟶ ℬ₀`, and `ℰ₀` is an object of `PSh(Ctx)/ℬ₀` with

```
ℰ₀ Γ β  :=  { e : ℰ₀ Γ  //  Γ ⊢ boundaryOf e ≈ β }
                             σ : Ξ ⟶ Γ  ⟹  ℰ₀ Γ β → ℰ₀ Ξ (σ ⋆ β)
```

the fibre taken up to `≈`. It is not a subpresheaf of `ℰ₀`, the boundary moving
under substitution.

**12.4.** `boundaryOf : ℰ₀ ⟶ ℬ₀` is **not** representable. Representability would
ask for an object extending `Γ` by one slot of boundary `β`, and an entry of a
telescope is a binding arity together with a boundary, of which 1.1 provides no
one-slot instance. It is representable exactly when the carrier supplies a
one-slot, nothing-binding arity, and then `ℬ₀` embeds into `𝒯₀` as the rank-0
single entries and 13.2 subsumes it. So `𝒯₀`, not `ℬ₀`, is the presheaf of types.

## 13. The natural model

A **natural model** is a representable natural transformation of presheaves:
`p : Ṫ ⟶ T` such that every pullback of `p` along a representable is
representable.

**Definition 13.1.** For `Γ : Ctx`,

```
𝒯̃₀ Γ  :=  Σ (Θ : 𝒯₀ Γ), Filling Γ Θ          q := fst : 𝒯̃₀ ⟶ 𝒯₀
```

with the dependent equivalence: `(Θ, τ) ≈ (Θ', τ')` iff

- `Γ ⊢ Θ ≈ Θ'` (7.4), whose first clause gives `|Θ| = |Θ'|` strictly; and
- for every `z : |Θ| ∋ Λ` with `Θ.boundary z` not an `eq`,
  `Γ ⋈ (τ ↾ z) ⋆ Θ.binding z ⊢ τ z ≈ τ' z`.

The second is not 9.2's `∼`: `τ` and `τ'` fill different telescopes. It typechecks
because `|Θ| = |Θ'|`, its ambient is built from the left pair, and "not an `eq`" is
unambiguous because 5.1 relates an `eq` only to an `eq`. That it is an equivalence,
and independent of which side builds the ambient, is 8(10) and 8(11).

For `σ : Ξ ⟶ Γ`, `σ ⋆ (Θ, τ) := (σ ⋆ Θ, σ ⋆ τ)`, the filling acted on
componentwise — which is `Subst.comp τ σ`. That it fills `σ ⋆ Θ` is 8(4), that it
respects the equivalence is 8(9). So `𝒯̃₀ : Ctxᵒᵖ ⥤ Setoid` and `q` is natural.

**Theorem 13.2 (representability).** For `Γ : Ctx` and `Θ : 𝒯₀ Γ` there is an
isomorphism of setoids, natural in `Ξ`,

```
Hom Ξ (Γ ⋈ Θ)   ≅   Σ (σ : Hom Ξ Γ), Filling Ξ (σ ⋆ Θ)
```

equivalently, the square

```
                    (⇑Θ, ν)
        y(Γ ⋈ Θ) ──────────→ 𝒯̃₀
            │                 │
   y(p Γ Θ) │                 │ q
            ↓         Θ       ↓
          y Γ ───────────────→ 𝒯₀
```

is a pullback in `PSh(Ctx)`, where the horizontals are the elements the two
presheaves receive by Yoneda: `Θ` below, and above the **generic**
telescope-with-filling

```
⇑Θ : 𝒯₀ (Γ ⋈ Θ)                    Θ read over the extended ambient (3.5)
ν  := Subst.ofRenaming C.inr       each slot of Θ filled by itself
```

`ν` fills `⇑Θ` by 8(5), its obligations at equational slots discharged by clause
6.5(2); it is the mirror of `p Γ Θ = Subst.ofRenaming C.inl`, the two being the
injections of a `C.copair`. The square commutes because `q` reads the first
component and `p ⋆ Θ = ⇑Θ`, acting by `Subst.ofRenaming ρ` being renaming along `ρ`
(`act_ofRenaming`). So **`q` is representable**: `𝒯̃₀ ⟶ 𝒯₀` is a natural model whose
types are telescopes and whose comprehension is context extension.

*Proof.* A morphism `Ξ ⟶ Γ ⋈ Θ` is a filling of `⇑(Γ ⋈ Θ)` over `Ξ`, that is one
component per slot of `Γ ⋈ Θ`. Those slots are `Γ`'s followed by `Θ`'s, so
splitting the family along `C.copair` gives `σ` on `Γ`'s slots and `τ` on `Θ`'s.
That `σ` is a morphism `Ξ ⟶ Γ` is its half of the premises; that `τ` fills `σ ⋆ Θ`
is the other half, a declaration of `Θ` mentioning `Γ`'s slots and 6.3
instantiating them by the components already given, which are exactly `σ`. Pairing
is the converse, and the two are mutually inverse because a family over `Γ ⋈ Θ` is
determined by its two halves. Both respect `∼`, which is slotwise, and naturality
in `Ξ` holds because both sides act by `σ ⋆ −`. ∎

The pullback is computed in setoids: its fibre at `σ` is
`Σ (Θ' : 𝒯₀ Ξ) (_ : Ξ ⊢ Θ' ≈ σ ⋆ Θ), Filling Ξ Θ'`, the `𝒯₀`-component matching
only up to `≈`; transporting a filling along a telescope equality, by 8(10),
identifies it with `Filling Ξ (σ ⋆ Θ)`.

**13.3.** If every entry of `Θ` is equational, `Filling Ξ (σ ⋆ Θ)` has at most one
element up to `∼` — its components are unconstrained and uncompared — and is
inhabited exactly when the instantiated equations hold. So `p Γ Θ` is monic:
extension by equations alone is a subobject inclusion.

**13.4 The three structural statements.**

```
★ 1.7    Expr            a relative monad over the slot functor    raw
★ 3.7    DTel            a monoid in ArityMod                      raw
  11.4   𝒯₀              a monoid in TelFam                        well formed, up to ≈
★ 13.2   q : 𝒯̃₀ ⟶ 𝒯₀     a natural model                           well formed, up to ≈
```

## 15. Open questions

Neither is needed to formalize §§1–13; both decide what the construction is *for*.

### 15.1 Semantics

Nothing above interprets the syntax. Two questions, in order.

**The baby case: sets.** A model of a well-formed ambient `Ξ` should send each slot
of `|Ξ|` to data of the shape its declaration names — a `sort` slot to a family of
sets indexed by the interpretations of the entries it binds, an `of S` slot to an
element of the family interpreting `S`, an `eq l r` slot to the *requirement* that
the interpretations of `l` and `r` coincide, since an equational slot carries no
data (13.3). Then: soundness, that `Ξ ⊢ e ≈ e'` implies equal interpretations; and
completeness, that the syntactic model is initial.

**The right generality.** The output of §13 is a natural model whose types are
**telescopes**, so a target should carry a class of display maps closed under
composition — a telescope is the composite of its entries, 10.4 — and under
pullback, which is 10.4's square. That is a **clan**, equivalently a display-map
category; Uemura's representable map categories are the same idea presented as a
condition on a functor. Three things to settle:

- whether a clan is enough, or the higher rank of §1 — a slot's binding arity being
  a whole telescope, not a list of types — forces a target with more structure;
- what the equational slots become. 13.3 makes `p Γ Θ` monic when every entry of
  `Θ` is equational, so the display class must contain those monomorphisms; a clan
  with a distinguished sub-class of *equational* displays may be the right notion;
- whether the setoid-first construction of §9 has an ∞-analogue — `≈` becoming a
  path rather than a quotient — and whether the general target is then an ∞-clan or
  a representable map ∞-category.

### 15.2 Named theories, and restricting the extensions

How does a particular theory — Martin-Löf type theory, say — sit here?

Its **signature is an ambient**: `Ξ_MLTT` declares `ty : sort`, `tm : [A : ty] sort`,
a former for each connective, and its equations. This is where higher rank is used:
`Π : [A : ty, B : [x : tm A] ty] ty` is a rank-2 entry. Fix `Ξ_MLTT` as a **prefix**
and ask that the contexts of the theory be the ambients `Ξ_MLTT ⋈ Θ`.

But not every `Θ : 𝒯₀ Ξ_MLTT` is an MLTT context — the telescopes here are richer.
An MLTT context is a `Θ` every entry `z` of which is

```
rank one          |Θ.binding z| = 1          the entry binds nothing
of-boundaried     Θ.boundary z = .of S       no sorts, no equations
```

So the question is what the sub-presheaf `𝒯₀^{of,1} ⊆ 𝒯₀` cut out by those two
conditions carries. Both are stable under `σ ⋆ −` — 2.3 for the second, 3.2.1 for
the first — and under `concatenate`, so it should be a sub-monoid of 11.4; whether
`q` restricts to a **natural model** over it is the real question, since 13.2's
pullback must land back inside the sub-presheaf.

The restriction is exactly 13.4's hypothesis. A rank-one `of`-boundaried entry *is*
extension by a single boundary, so `𝒯₀^{of,1}` is where `ℬ₀` embeds into `𝒯₀` and
`boundaryOf : ℰ₀ ⟶ ℬ₀` becomes representable — the ordinary natural model of a
type theory, recovered inside the telescopic one. Two further questions: whether
the prefix must be fixed, or whether "theory = ambient, contexts = restricted
extensions" works uniformly over `Ctx`; and which theories need which restriction —
a rank-1 theory with sorts but no equations, a rank-2 signature with rank-1
contexts, and so on.
